# Package io.github.umbrellaleaf5.kotlinbrella.test

Contract helpers for consuming application test suites.

`ErrorDocsParity.assertParity` compares documented error examples with real MVC
responses, including HTTP method, strict JSON types, and unexpected fields. See
the [parity guide](https://github.com/UmbrellaLeaf5/kotlinbrella/blob/main/GUIDE.md#testing-docs-against-runtime).
